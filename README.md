# 換算前フローフロント温度電圧データ抽出

射出成形で計測したフローフロント（流動中の樹脂）温度センサの電圧データ（温度に換算する前の生電圧 CSV）から、
**最高値・変曲点（肩）・立ち上がり点などの特徴量を一括で抽出する** Jupyter Notebook 群です。

抽出したい点の考え方によって、2 つのバージョンに分かれています。

| バージョン | 抽出する点 | 状況 |
|---|---|---|
| `最高値version/` | 平滑化後の波形の **最高値** | 特徴量抽出と、グラフ用のデータ圧縮コード |
| `変曲点version/` | 立ち上がり後に上昇が鈍る **変曲点（肩）** | 相対値方式と加速度方式（加速度方式は不採用） |

---

各バージョンの `README.md` は現時点では空です。

`加工対象ファイルサンプル/` には、データロガー NR-500 で記録した実測 CSV が入っています。
加熱シリンダ温度はすべて 210℃ で、射出速度とキャビティ厚み（0.5〜2.0 mm）を変えた条件のデータです。
サンプリング周期は 5 μs のファイルが大半（39 ファイル）で、10 μs と 20 μs のファイルが 2 つずつあります。周期はファイルごとにヘッダーから読み取るので、混在していても問題ありません。

## 環境構築と実行方法

### 環境構築

[uv](https://docs.astral.sh/uv/) で環境を管理しています。リポジトリ直下で次を実行してください。

```bash
uv sync
```

`.venv` が作成され、以下のパッケージが入ります。

- pandas / numpy / scipy … データ読み込み・フィルタ処理
- matplotlib / pillow … グラフ画像の作成
- openpyxl / xlsxwriter … Excel 出力
- ipykernel … VS Code / Jupyter でノートブックを実行するため

ファイル・フォルダ選択ダイアログには tkinter（Python 標準ライブラリ）を使います。

### 実行手順（特徴量抽出ノートブック）

1. VS Code で目的の `.ipynb` を開き、カーネルに `.venv`（resin-voltage-feature-extraction）を選ぶ
2. 必要に応じて **セル2（設定セクション）** の値を変更する
3. セル1 → セル2 → セル3 → セル4 の順に実行する
   - セル4 でフォルダ選択ダイアログが開くので、解析したい CSV が入っている **メインフォルダ** を選ぶ
   - ダイアログが他のウィンドウの裏に隠れていることがあります
4. セル5 を実行すると、特徴量の一覧 CSV がメインフォルダに保存される
5. （任意）セル6 を実行すると、全ファイルのグラフを貼り付けた Excel がメインフォルダに保存される

まず試してみるときは、メインフォルダに `加工対象ファイルサンプル/` を選んでください。
その場合、出力ファイルもこのフォルダ（リポジトリ内）に作られます。誤ってコミットしないよう注意してください。

## 入力データの前提

| 項目 | 内容 |
|---|---|
| 形式 | CSV（文字コード **cp932 / Shift-JIS**） |
| ヘッダー | 先頭 **70 行** を読み飛ばし、71 行目を列名として読む（NR-500 の出力では `#BeginHeader,71` から `#EndHeader,…` までの 71 行がヘッダーで、最後の行に列名が並ぶ） |
| サンプリング周波数 | 先頭 50 行の中にある `サンプリング周期 … NNμs` の行から自動で計算する（見つからない場合は 100 kHz とみなす） |
| 対象列 | `(1)HA-V05` |
| フォルダ構成 | メインフォルダ配下の CSV を **サブフォルダも含めて再帰的に** 探し、サブフォルダ単位でまとめる |
| 除外 | このリポジトリのコードが出力した CSV は処理しない：`summary_`・`max_summary_` で始まるもの（特徴量一覧）、`_smoothed_10k.csv` で終わるもの（データ圧縮コードの出力） |
| ファイル末尾 | NR-500 が末尾に付けるマーク情報（`#BeginMark` 〜 `#EndMark` の行）は、データではないので自動で取り除く |

### ファイル名の命名規則

成形条件はファイル名から読み取ります。`_` 区切りで次の 4 つの項目を並べてください。

```
番号_加熱シリンダ温度_射出速度_キャビティ厚み.csv
例：003_210℃_003_1.5mm.csv（番号 3、210℃、射出速度 3 mm/s、厚み 1.5 mm）
```

温度に付けた `℃`、厚みに付けた `mm` は自動で取り除かれて数値になります。`003` のような 0 埋めもそのまま数値として扱われます。
先頭の番号は並べ替えにだけ使い、特徴量一覧の CSV には出力しません（サンプルでは、同じ番号が別の条件にも使われています）。

## 処理の流れ（特徴量抽出ノートブック共通）

| セル | 内容 |
|---|---|
| セル1 | ライブラリの読み込み（matplotlib は画面表示しない `Agg` モード） |
| セル2 | 設定値の定義 |
| セル3 | 関数の定義（`process_file`：1ファイル分の処理、`generate_plot_image`：グラフ画像の作成） |
| セル4 | メインフォルダの選択と CSV の検索 |
| セル5 | 全ファイルの特徴量を抽出し、CSV に保存 |
| セル6 | （任意）グラフを作成し、Excel に一覧で貼り付けて保存 |

1 ファイルあたりの処理（`process_file`）は次のとおりです。

1. CSV を読み込む（`END_TIME_SEC` を指定した場合は、その時刻までの行だけを読む）
2. ファイル末尾のマーク情報（`#BeginMark`・`#EndMark` の行）を取り除く
3. サンプリング周波数から時間軸 `Time (s)` を作る（時間はファイル先頭を 0 秒とする）
4. **5 次の Butterworth ローパスフィルタ（カットオフ 300 Hz）** をゼロ位相（`sosfiltfilt`）でかけて平滑化する
   - 切り出し区間の端が歪まないように、フィルタは切り出す前のデータ全体にかけている
5. `START_TIME_SEC` 秒より後を切り出す
   - 秒から行数への換算はサンプリング周期をもとに自動で行うので、周期が違うファイルでも同じ時間を切り捨てる
6. 平滑化後の波形から特徴量を求める（求め方はノートブックによって異なる。次の章を参照）

どのノートブックでも共通して求める特徴量は次の 2 つです。

- **立ち上がり点**：平滑化後の電圧が初めて `RISE_THRESHOLD_V`（2.0 V）以上になった点
- **0.7 秒前の点**：最高値（または抽出ピーク）の時刻から `TIME_BEFORE_MAX_SEC`（0.7 秒）さかのぼった時刻以前で、最も近いデータ点。存在しなければ空欄

## 各ノートブックの説明

### 最高値version / 電圧特徴量(最高値他)抽出.ipynb

- 切り出し区間内で、平滑化後の電圧が **最大になる点** を「最高値」として抽出します。
- 解析範囲：`START_TIME_SEC = 1.0`（最初の 1 秒は使わない）、`END_TIME_SEC = None`（ファイルの最後まで）
- 出力：`max_summary_all_features.csv`、`max_summary_plots_COMBINED_{従来版|透かし版}.xlsx`

### 最高値version / データ圧縮コード_1ファイルのみ.ipynb

外部のグラフ作成ソフトで扱いやすくするため、**CSV 1 ファイルを平滑化して約 1 万行に間引く** コードです。特徴量の抽出は行いません。

1. ファイル選択ダイアログで CSV を 1 つ選ぶ
2. 末尾のマーク情報を取り除き、データ全体に移動平均（中心窓）をかける
   - 窓幅 ＝（全行数 ÷ `TARGET_ROW_COUNT`）×`SMOOTHING_FACTOR`。奇数に丸め、最小 3 点
3. 切り出す区間を決めて切り出す
   - `CLIP_MODE = 'auto'`（初期値）：平滑化後の電圧が初めて `RISE_THRESHOLD_V`（2.0 V）以上になった時刻を立ち上がりとし、その `BEFORE_RISE_SEC`（2 秒）前から `AFTER_RISE_SEC`（2 秒）後までを切り出す。立ち上がりが見つからないときは、警告を出して `'fixed'` の範囲を使う
   - `CLIP_MODE = 'fixed'`：`START_TIME_SEC`〜`END_TIME_SEC`（初期値は 0〜4 秒）を切り出す
4. 約 `TARGET_ROW_COUNT`（10,000）行になるよう一定間隔で間引く
5. 入力ファイルと同じフォルダに、次の 2 つを出力する
   - `{元ファイル名}_smoothed_10k.csv`（列：`Time (s)`, `(1)HA-V05_smoothed`）
   - `{元ファイル名}_smoothed_10k_graph.png`

### 変曲点version / 電圧特徴量(最高値他)抽出.ipynb

最高値version の同名ノートブックと同じ処理です（解析範囲も同じ `START_TIME_SEC = 1.0`）。
違いは、出力ファイル名に `max_` が付かないことだけです（`summary_all_features.csv`、`summary_plots_COMBINED_*.xlsx`）。

### 変曲点version / 電圧特徴量抽出(相対値方式で変曲点抽出).ipynb

**立ち上がり後に上昇速度が十分に落ちた点（肩）** を「抽出ピーク」とします。

1. 平滑化後の波形を 1 階微分して、上昇速度を求める
2. 立ち上がり点以降で、上昇速度が最大になる点を探す
3. その点以降で、上昇速度が「最大速度 × `SHOULDER_THRESHOLD_PERCENT` %」（初期値 **2.0 %**）以下に **初めて** 落ちた点を抽出ピークとする
   - 該当する点がなければ、速度が最小の点を使う
   - 立ち上がり点が見つからなければ、最大値の点を使う

解析範囲は `START_TIME_SEC = 0.0`（ファイル全体）です。

グラフの X 軸は、ファイルごとに自動で決まります（`X_AXIS_LIM = 'auto'`）。
0.7 秒前の点・立ち上がり点・抽出ピークがすべて入るように、前後へ `X_AUTO_MARGIN_SEC`（0.5 秒）の余白をとって、立ち上がり部分を拡大して表示します。
`X_AXIS_LIM = (2.5, 4.5)` のように書けば、全ファイル共通の固定範囲にもできます。Y 軸は 0〜5 V です。

### 変曲点version / 電圧特徴量抽出(加速度方式で変曲点抽出).ipynb 【不採用】

上昇速度の変化率（加速度 ＝ 2 階微分）に注目し、**急上昇に最も強くブレーキがかかった瞬間** を抽出する方式です。

1. 立ち上がり点以降で、上昇速度が最大になる点を探す
2. そこから速度が 0 以下になるまでの区間で、加速度が最小（最も負）になる点を抽出ピークとする

> 不採用の理由（ノートブック内のメモより）：最高値だけでなく最高値の肩の値も抽出したかったが、この方式で求まるのは変曲点なので、元の波形の凸部分（肩）をとらえられない。

## 出力ファイル

### 特徴量一覧 CSV（セル5）

メインフォルダに `utf-8-sig`（Excel でそのまま開ける UTF-8）で保存されます。
行は **キャビティ厚み → 加熱シリンダ温度 → 射出速度 → ファイル番号** の順に並びます。

| 列 | 内容 |
|---|---|
| 元ファイル | CSV ファイル名 |
| キャビティ厚み[mm] / 加熱シリンダ温度[℃] / 射出速度[mm/s] | ファイル名から読み取った成形条件 |
| `(1)HA-V05_最高値(V)` / `_最高値の時間(s)` | 最高値とその時刻（最高値版） |
| `(1)HA-V05_抽出ピーク値(V)` / `_抽出ピーク時間(s)` | 抽出ピークとその時刻（変曲点版の 2 方式） |
| `(1)HA-V05_0.7秒前の値(V)` / `_0.7秒前の時間(s)` | ピークの 0.7 秒前の値と時刻 |
| `(1)HA-V05_立ち上がり値(V)` / `_立ち上がり時間(s)` | 立ち上がり点の値と時刻 |

値はすべて平滑化後の波形から取り、時刻はファイル先頭からの経過秒数です。

### グラフ一覧 Excel（セル6・任意）

- `All_Graphs` シートの A 列にサブフォルダ名を書き、その行の B 列以降にグラフを横に並べて貼り付けます。
  グラフの並び順は CSV と同じく、キャビティ厚み → 加熱シリンダ温度 → 射出速度 → ファイル番号の順です。
- グラフには元波形（灰色）、平滑化後の波形（青）と、次の 3 つの点を描きます。
  - 赤の星：最高値または抽出ピーク
  - 水色の星：0.7 秒前の点
  - 緑の星：立ち上がり点（しきい値の線も表示）
- `PLOT_STYLE` で描き方を選べます。どちらを選んだかがファイル名に付きます。
  - `1` ＝ 従来版：青い平滑化波形を強調する
  - `2` ＝ 透かし版：元波形を濃くし、平滑化波形を半透明にする

## 注意点

- **出力ファイルは入力フォルダに作られる**
  特徴量一覧 CSV・グラフ Excel・圧縮データは、どれも入力 CSV があるフォルダに保存されます。再実行しても入力として読み込まれることはありませんが（「入力データの前提」の「除外」を参照）、サンプルフォルダで試したときはコミットに含めないよう注意してください。
- **立ち上がりのしきい値は絶対電圧**
  オフセットを補正していないので、センサやロガーの条件が変わったら `RISE_THRESHOLD_V` を見直してください。
- **データ圧縮コードの平滑化の強さは、サンプリング周期で変わる**
  移動平均の窓幅を行数から決めているため、窓の時間幅はサンプルの 5 μs のファイルで約 2 ms、10・20 μs のファイルで約 4 ms になります。周期の違うファイルの圧縮データを比べるときは注意してください。
- **メモリ使用量**
  ファイル全体（サンプルでは 100 万〜200 万行）を読み込み、フィルタ処理も行うため、メモリを多く使います。
- **ダイアログが隠れる**
  ファイル・フォルダ選択ダイアログは最前面に表示する設定ですが、それでも裏に隠れることがあります。
